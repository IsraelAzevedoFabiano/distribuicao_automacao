# Justiça Ágil — distribuição

Este repositório serve só para distribuir o robô Justiça Ágil.

## Instalar o robô

**Clique aqui para baixar o instalador:**
👉 [justica-agil-instalador.zip](https://github.com/IsraelAzevedoFabiano/distribuicao_automacao/releases/latest/download/justica-agil-instalador.zip) (~60 MB)

Depois de baixar:

1. **Feche o robô** se ele estiver aberto (a janela preta e o navegador).
2. **Extraia o zip inteiro** para uma pasta qualquer (botão direito → *Extrair tudo*).
3. Dentro da pasta extraída, dê dois cliques em **`Instalar Justica Agil.bat`**.
4. Use o atalho **Justiça Ágil** que aparece na área de trabalho.
   Na primeira abertura a janela preta fica parada alguns minutos baixando e
   preparando o robô — não feche. O navegador abre sozinho quando estiver pronto.

Atualizações chegam sozinhas: quando houver versão nova, aparece um aviso na tela
inicial do robô — é só clicar em **Atualizar**. Não precisa baixar o instalador de
novo.

Outros links (para conferência, não precisa clicar para instalar):

- [Página de todas as versões publicadas](https://github.com/IsraelAzevedoFabiano/distribuicao_automacao/releases) — o que mudou em cada uma.
- [Versão mais recente](https://github.com/IsraelAzevedoFabiano/distribuicao_automacao/releases/latest) — os demais arquivos dessa página (`justica-agil-vX.Y.Z.zip`, `manifest.json`, `vcredist.zip`) são baixados pelo próprio robô; **não** são instaladores.
